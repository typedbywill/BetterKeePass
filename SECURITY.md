# Política de Segurança

## Relatando uma vulnerabilidade

Se você encontrar uma vulnerabilidade de segurança no BetterKeePass (especialmente em tratamento de memória, criptografia, isolamento do WebView, IPC da extensão ou parser KDBX), **não abra uma issue pública**.

Entre em contato diretamente com os mantenedores do repositório de forma privada (via GitHub Security Advisories quando habilitado no repositório) incluindo:

- Descrição do problema e impacto potencial;
- Passos para reproduzir ou prova de conceito;
- Versão ou commit afetado.

## Escopo

Consulte o [Modelo de Ameaças](docs/threat-model.md) para entender as fronteiras de confiança e os riscos já mitigados ou fora de escopo.
